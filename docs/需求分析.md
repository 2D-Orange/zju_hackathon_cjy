# 需求分析

## 赛题目标

面向"AI 全栈极速黑客松：学科知识整合智能体开发"，构建一个 Web 应用，将多本医学教材整合为统一的知识体系。系统需支持教材上传解析、知识图谱构建、跨教材知识整合去重、带原文引用的 RAG 问答、教师多轮反馈，并提供完整的文档和报告。

## 用户角色

| 角色 | 需求描述 |
|------|----------|
| 学生 / 研究者 | 通过图谱浏览跨教材知识关联；用自然语言提问并获得带教材原文引用的回答 |
| 教师 / 评审 | 审核整合决策的合理性；通过自然语言反馈修正合并、保留或移除决策 |
| 开发者 / 运维 | 按 README 本地启动项目；通过 Docker 一键部署；配置 LLM / Embedding 提供方 |

## P0 功能（必须完成）

### 1. 教材上传与解析
- **输入**：PDF / Markdown / TXT 格式的医学教材文件
- **处理**：PDF 使用 PyMuPDF 逐页解析并识别章节标题；Markdown 按标题层级分割；TXT 按正则匹配章节
- **输出**：每本教材的章节列表，包含 chapter_id、title、page_start、page_end、content、char_count
- **验收**：上传后前端出现教材条目；点击可查看章节列表；解析失败有明确错误提示

### 2. 知识图谱构建
- **输入**：已解析教材的章节文本
- **处理**：从每章提取 3-8 个知识点（支持 mock 规则提取和 LLM 提取两种模式）；构建 prerequisite / parallel / contains / applies_to 四类关系边
- **输出**：节点含 id、name、definition、category、textbook_id、chapter、page、source_text；边含 source、target、relation_type、label、weight
- **验收**：图谱可视化展示节点和关系；节点可点击查看详情和原文出处；不同教材来源用颜色区分；节点大小体现频次

### 3. 跨教材整合
- **输入**：至少两本已解析教材的知识图谱节点
- **处理**：用 embedding 相似度召回候选对；通过阈值判定 same_concept / broader_narrower / related；使用并查集聚类相同概念；生成 merge / keep / remove 决策
- **输出**：整合决策列表，每项含 action、reason、confidence、affected_nodes、result_node；压缩统计含 decision_count、merge/keep/remove 计数、compression_ratio
- **验收**：展示决策列表和理由；压缩比可视化；决策可被教师修改

### 4. RAG 问答
- **输入**：已解析教材的完整内容
- **处理**：按 700 字 chunk、80 字重叠分块；每块保留 textbook、chapter、page_start/page_end 元数据；本地 hash embedding 作为 fallback
- **输出**：带原文引用的回答，引用格式 `[教材, 章节, 页码]`
- **验收**：输入问题后返回回答和引用列表；引用可展开查看原文 chunk；知识库未覆盖时返回兜底话术

### 5. 教师多轮反馈
- **输入**：教师的自然语言消息（可关联特定整合决策）
- **处理**：解析意图（解释 / 修改 / 澄清）；对修改意图匹配 merge/keep/remove 操作；更新决策并持久化
- **输出**：助手回答 + 更新后的决策（如有）
- **验收**：对话历史在同会话中保留；修改决策后整合面板实时反映

### 6. 整合报告
- **输入**：系统所有模块的实时状态
- **处理**：汇总教材数、章节数、图谱节点/边数、整合决策统计、压缩比、RAG 索引状态、对话会话数
- **输出**：报告摘要 JSON + 前端可视化面板
- **验收**：报告 Tab 展示非零统计数据；数字来自系统真实输出

### 7. Web 单页应用
- **左侧**：上传区 + 教材列表 + 统计条
- **中间**：ECharts 力导向知识图谱，支持缩放拖拽和节点点击
- **右侧**：Tab 面板（整合 / RAG / 对话 / 报告）
- **验收**：1920×1080 分辨率下三栏完整可用

## P1 功能（加分项）

1. 图谱搜索 / 筛选：按关键词或类别过滤节点
2. 混合检索：向量 + BM25 + 简单 rerank
3. 自建 RAG benchmark：20-50 个问题统计命中率、引用准确率、响应时间
4. 整合前后图谱对比视图
5. Docker 一键部署
6. Token / 耗时统计
7. 报告导出 PDF

## 验收标准

- README 能让新开发者在 5 分钟内本地启动
- 上传 PDF/MD/TXT 后能解析出章节
- 至少一本书能生成图谱并可视化
- 至少两本书能产生跨教材整合决策
- RAG 问答有引用，引用可展开原文 chunk
- 教师能修改一项整合决策，界面有反馈
- 报告 Tab 统计数据来自系统真实输出
- 仓库不包含教材 PDF、.env、缓存索引或构建产物
