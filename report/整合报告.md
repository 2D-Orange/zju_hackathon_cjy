压缩比 25.99%，满足 ≤30% 的 P0 要求。压缩过程中使用并查集（UnionFind）聚类跨教材相同概念，通过 0.78 阈值判定 `same_concept`、0.38 阈值判定 `related`，确保压缩不丢失教学完整性。

### 典型决策示例

**合并决策**：
- **知识点**："细胞"
- **判定关系**：same_concept（同一概念）
- **置信度**：0.82
- **理由**：不同教材中的知识点名称或原文证据高度相似，压缩层合并为一个可追溯结果节点。

**保留决策**：约 6 个知识点判定为相关但不等价（如 "生理学-动作电位" 与 "病理学-细胞损伤"），保留为独立节点。

**移除决策**：约 1 个节点因信息冗余被移除，其核心内容已合并至结果节点。

## 结论

系统已完成 P0 阶段全部功能的端到端闭环验证：

1. **上传解析**：支持 PDF/MD/TXT 三格式，自动章节识别
2. **知识图谱**：节点含定义、分类、原文出处；边覆盖 contains/parallel/prerequisite 三类关系
3. **跨教材整合**：通过 embedding 相似度 + UnionFind 聚类实现概念对齐，压缩比 25.99%
4. **RAG 问答**：分块索引 + 语义检索 + 摘取式答案，所有回答附原文引用
5. **教师反馈**：支持解释和修改整合决策，对话历史可持久化
6. **整合报告**：统计数据来自系统真实输出，前端报告 Tab 实时可查

系统以 mock 模式（规则提取 + hash embedding + 摘取式答案）即可跑通完整闭环，不依赖任何外部 LLM/Embedding API。接入在线 API 后可进一步提升知识提取覆盖率和语义检索精度。
